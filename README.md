# 🔐 SecurePass Manager

Modern JavaFX password manager focused on security and credential management.

## Features

- Login system
- User registration
- Dashboard
- JavaFX UI
- FXML architecture
- CSS styling
- Scene navigation

## Technologies

- Java 21+
- JavaFX
- Maven
- IntelliJ IDEA
- Git & GitHub
